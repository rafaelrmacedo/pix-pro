# Roadmap Inicial - PixPro

## Objetivo do roadmap

Organizar o inicio do projeto no GitLab com foco em Sprint 1 e base escalavel para os proximos ciclos.

## Epicos

1. Setup do projeto
2. Autenticacao
3. Upload de imagens
4. Processamento de imagens
5. Notificacoes em tempo real
6. Projetos e organizacao

## Sprint 1 - Tarefas

1. Setup frontend (React + TS)
2. Setup backend (Node + Express)
3. Estrutura de microsservicos
4. Autenticacao basica
5. Upload de imagem (mock)
6. Processamento inicial (mock)
7. WebSocket basico (status)
8. Configuracao Docker
9. Documentacao inicial

## Sugestao de organizacao no GitLab

- Criar labels: `epic`, `sprint-1`, `backend`, `frontend`, `infra`, `docs`.
- Criar um board com colunas: `Backlog`, `To Do`, `In Progress`, `Review`, `Done`.
- Relacionar cada issue com seu epic correspondente.
