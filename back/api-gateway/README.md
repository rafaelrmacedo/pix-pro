# API Gateway

Single entry point for PixPro clients.

## Responsibilities

- Expose public HTTP routes
- Centralize routing to services
- Provide basic health monitoring

## Main endpoints

- `GET /health`
- `GET /api/services`
- `GET /api/auth/health`
- `GET /api/image/health`
- `GET /api/project/health`
- `GET /api/notification/health`
